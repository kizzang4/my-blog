클로드 코드와 함께 블로그를 만들면서 웹의 세 가지 기본 기술이 각각 어떤 일을 하는지 알게 됐습니다. 집을 짓는 일에 빗대면 이해하기 쉽습니다.

## HTML: 뼈대

HTML은 페이지에 **무엇이 있는지**를 정합니다. 제목, 문단, 링크, 이미지처럼 내용의 구조를 담당합니다.

- `<header>`, `<main>`, `<footer>`처럼 의미 있는 태그로 영역을 나눕니다.
- 이 블로그에서는 `index.html` 하나가 모든 화면의 틀이 됩니다.
- 구조가 정확해야 스크린 리더 같은 보조 도구도 글을 제대로 읽습니다.

## CSS: 겉모습

CSS는 그 내용이 **어떻게 보이는지**를 정합니다. 색, 글꼴, 여백, 배치가 모두 CSS의 몫입니다.

- 색상을 CSS 변수로 모아 두면 라이트 모드와 다크 모드를 변수 값만 바꿔서 전환할 수 있습니다.
- 미디어 쿼리로 화면 너비에 따라 레이아웃을 바꿔 모바일에서도 읽기 좋게 만듭니다.
- 본문 너비와 줄 간격만 다듬어도 글의 가독성이 크게 달라집니다.

## JavaScript: 동작

JavaScript는 페이지가 **어떻게 움직이는지**를 정합니다. 사용자의 행동에 반응하고 내용을 바꿉니다.

- `fetch()`로 마크다운 파일을 불러옵니다.
- 직접 만든 변환기가 마크다운을 HTML로 바꿉니다.
- 주소의 해시(`#/post/slug`)를 보고 어떤 글을 보여 줄지 정합니다.
- 다크 모드 토글을 눌렀을 때 선택을 저장합니다.

## 한눈에 정리

| 기술 | 역할 | 이 블로그에서 |
| --- | --- | --- |
| HTML | 구조 | 헤더, 본문, 푸터의 틀 |
| CSS | 디자인 | 다크 모드, 반응형 레이아웃 |
| JavaScript | 동작 | 글 불러오기, 라우팅, 테마 토글 |
